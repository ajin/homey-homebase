Homebase controls your devices directly from Homey Pro, over your own home network or Bluetooth, without vendor accounts, clouds or an internet connection. It brings several kinds of devices together in one app, each with its own driver.

Supported so far: Bluetooth LED lights with a Zengge controller, the kind set up with the Surplife phone app, such as Quntis smart Christmas string lights. This is an unofficial app, not affiliated with the makers of the supported devices.
