Teach your remote

Homey listens on 433 MHz for your Hamulight remote.

  1. Stand within a few metres of Homey with the remote.
  2. Press the on/off button once.

Listening… codes heard: none yet

Remote found.

Remote id , on/off code

The light should switch after a few seconds (Homey takes a moment before it sends). If it does not, move the remote closer and tap "Start again".

Brightness is calculated for this remote, so there is nothing more to teach.

Enter the on/off code yourself

If you captured the code with another receiver: 8 hex digits, e.g. 4516A050.

  1. Switch the light on with the remote.
  2. Slide your finger slowly along the brightness ring, from darkest to brightest, once.

Brightness levels learned: 0

More levels give smoother dimming. If you went the wrong way, tap "Start again".

You can skip this: Homey then tries calculated brightness codes, which may not work with every remote. You can teach the ring later with Repair.
